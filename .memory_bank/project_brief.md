# R2D2 Project Brief

## Что это

R2D2 — это платформа для бэктестинга и автоматической торговли криптовалютами, разработанная на Python с использованием FastAPI и Vue.js.

## Основные функции

- **Написание стратегий на Python** — пользователи могут создавать торговые стратегии, наследуя от базового класса `Strategy` и реализуя методы `on_start()`, `on_bar()`, `on_finish()`
- **Бэктестинг** — запуск стратегий на исторических данных с визуализацией результатов
- **Live-торговля** — запуск стратегий в реальном времени на бирже
- **Графический интерфейс** — веб-интерфейс для управления стратегиями, просмотра графиков и результатов

## Ключевые решения

- **Поддержка нескольких бирж** — через ccxt (Bybit, Binance и другие)
- **Гибкая система ордеров** — market, limit, stop ордера с возможностью группировки в сделки (deals)
- **SLTP-ордера** — автоматическое управление стоп-лоссами и тейк-профитами через `buy_sltp()` / `sell_sltp()`
- **modify_deal** — изменение существующей сделки без закрытия позиции
- **Кросс-таймфрейм индикаторы** — возможность использовать индикаторы с других таймфреймов без look-ahead bias
- **Система индикаторов** — поддержка TA-Lib и pyita с визуализацией на графике

## Ограничения

- **Только криптовалюты** — платформа предназначена исключительно для криптовалютных рынков
- **Python 3.10+** — минимальная версия Python для работы системы
- **Redis и ClickHouse** — обязательные зависимости для хранения состояния и котировок
