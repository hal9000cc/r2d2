# R2D2 Current State

## Что реализовано

### Backend — Core
- [x] FastAPI приложение с CORS, lifespan (startup/shutdown)
- [x] Конфигурация через `~/.config/r2d2/.env` с авто-созданием файлов
- [x] Redis хранилище через Objects2Redis / Objects2RedisList

### Backend — Система ордеров (broker.py)

- [x] Абстрактный класс `Broker` с полной логикой управления ордерами
- [x] Market, Limit, Stop ордера
- [x] Группировка ордеров в сделки (deals) с типами LONG/SHORT
- [x] SLTP-сделки: `buy_sltp()` / `sell_sltp()` с множественными стоп-лоссами и тейк-профитами
- [x] `modify_deal()` — изменение существующей сделки (вход, стоп, тейк)
- [x] `cancel_orders()` — отмена ордеров
- [x] `deal_info()` — получение информации о сделке
- [x] Автоматический расчёт объёмов стоп/тейк при частичном исполнении
- [x] Форматирование объёмов и цен по точности биржи

## Известные особенности

- Результаты бэктестинга хранятся в Redis (не персистентно — перезапуск Redis очистит их)
- Стратегии хранятся в `~/.local/share/r2d2/strategies/` на диске
- Бэктестинг запускается в отдельном процессе (не async)
- При одновременном срабатывании стоп-лосса и тейк-профита — приоритет у стоп-лосса
